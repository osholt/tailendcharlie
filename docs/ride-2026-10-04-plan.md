# 4 October 2026 group ride: fix and validation plan

Source: three-rider group ride to Penelope's Cafe (Goytre Wharf) on build
1.0.1+101, followed by solo Where To legs from the cafe and from Aust services to
east Bristol. Feedback came from the operator, Becks (Android) and Nigel.
Raw GPX and diagnostics stay private; the root causes are recorded on each ticket.

The feedback was positive overall. This is the work between build 101 and an
open beta.

## Evidence limits

- **Bluetooth peer-to-peer is not evidenced.** The shared diagnostics are solo
  navigation logs, and the recorder logs no transport events at all. #855 adds
  that instrument; #268 stays open until a group ride is recorded with it.
- The Usk to Chepstow leg has no diagnostics. Its fault was reconstructed
  from the live router response.

## Phase 1: navigation correctness (build 102)

Every fix carries a regression test built from the recorded router steps, using
only the junction-local excerpt and never a rider's start or end point. Every fix
is mutation-tested. No fix may special-case a location.

| Ticket | Root cause (detail on ticket) | General fix |
| --- | --- | --- |
| #839 shaping points spoken as destinations | `RouteReshapePlanner` and `RouteGeometryEnricher` send shaping points as stops, so each leg ends in an arrival | Send shaping points through the non-stopping API (OSRM `waypoints=`, Valhalla `through`) already used by the circular planner. Only named stops split legs. |
| #853 Usk merge then left spoken as straight on | The #302 bearing override in `_maneuverDirection` overrules the engine's "left" at an 8° diverge. The parser discards the competing branch bearings. | Keep junction branches on each manoeuvre. Never reduce a stated left or right to straight when another usable branch is within about 30°; say "Keep left". |
| #851 invented forks, "follow the road", road label "Turn" | `_ambiguousStraightJunctions` (#774) invents a fork at every motorway off-slip. `roadLabel` falls back to the step type as a road name. | Treat continuity of the major road (same name or ref, then Valhalla road class) as "follow the road" or silence. Announce only real departures. Remove the step-type fallback. Fix the capitalised second clause. |
| #840 canal track at Goytre | The default preferences route through OSRM on the false assumption that it avoids `highway=track`. Public Valhalla motorcycle costing ignores `exclude_unpaved`. Nothing checks the returned route. | Validate each planned route with one `trace_attributes` call. Re-plan or warn when it uses track or unpaved edges without explicit vehicle access. Correct the misleading preference label. |
| #856 Aust roundabout "1st exit, left" | Not yet analysed | Ring-geometry rule fix |
| #852 Welsh 20 mph | OSM `maxspeed=20` on the B4293 and B4598, not app inference | The operator confirms the signed limits, and OSM is corrected with `source:maxspeed=sign`. Fix the `GB:nsl_restricted` mapping in `tools/discovery`. |

## Next-ride validation checklist

Record diagnostics on every phone for the group ride itself, not only for Where To.

- **Transport:** with #855 shipped, Nearby-only stretches show peer events
  received (#268, #134).
- **Membership:** leave and rejoin. The count matches on every phone, and the
  departed rider stays listed (#27, #33, #144, #99).
- **Pre-start:** riders are visible to each other before Start, and the saved GPX
  has no pre-start trail (#35, #51, #300).
- **Android minimap:** a screenshot with real roads in light and dark (#29).
  The iOS minimap keeps updating for the whole ride (#737, #744).
- **Natural voice:** count fallbacks in the log (#616). An alert is spoken in the
  natural voice (#545).
- **Speed sign and ETA:** live speed never freezes or flickers (#655, #285, #164).
  On iOS, the ETA is stable and the map is course-up (#742, #760).
- **After stops:** remaining distance and time stay correct after each stop
  (#822). Ending the ride is responsive and leader-only (#165, #244, #380).
- **Phone behaviour:** the screen stays awake (#50, #607). No heat while idle
  (#763). Backgrounded riders keep a trail (#205).
- **Where To recordings:** Where To rides appear in the library with recap export
  (#659).
